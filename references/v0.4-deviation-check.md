## 3. 细微差异 / 实现说明

### 3.1 normalize dry-run 模式

Dev Doc 测试要点提及 `dry-run`，但 WP1 关键点未明确列出。**补充**：normalize 默认 `dry-run=false`，但提供 `--dry-run` 参数仅产出报告不写入。

### 3.2 import 重复检测

Dev Doc 提及「重复检测」，但未指定算法。**补充**：基于 `(title + domain) hash` 或 `(source.url)` 做幂等键；与 v0.1 capture 标题去重一致。

### 3.3 config 校验

Dev Doc 说「校验：缺失字段走默认值」。**补充**：校验失败时记 warning 不阻塞；可选 schema 文件 `references/kb-config-schema.yaml` 供外部校验工具用。

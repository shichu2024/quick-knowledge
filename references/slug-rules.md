# Slug 命名规则

## 规则

1. **文件名组成**：文件名 = basename + `.md`，basename 使用 kebab-case
2. **中文处理**：
   - 保留中文（不转拼音），使用 kebab-case 分词
   - 示例：`混合检索设计.md` → `混合检索设计.md`（已是合法格式）
   - 备选：若用户提供英文翻译优先使用英文，否则保留中文
3. **长度限制**：basename ≤ 50 字符（中文按 1 字符计）
4. **禁止字符**：空格（转换为 `-`）、`/`、`\`、`:`、`*`、`?`、`"`、`<`、`>`、`|`
5. **数字前缀**：仅允许以下两种场景：
   - 日期前缀：`2026-08-14-...`
   - inbox 序号：`inbox-001`、`inbox-002`

## 示例

| 标题 | 推荐文件名 | 备注 |
|------|-----------|------|
| 混合检索设计 | `混合检索设计.md` | 保留中文 |
| RAG 架构设计 | `rag架构设计.md` | 中文+英文混合 |
| 2026-08-14 AI 工程会议 | `2026-08-14-ai工程会议.md` | 日期前缀 |
| Inbox 第 3 条 | `inbox-003.md` | inbox 序号 |

## 引用

本规则被以下 SKILL 引用：
- `skills/quick-kb-capture/SKILL.md`（笔记创建时生成 slug）
- `skills/quick-kb-ingest/SKILL.md`（入库时验证 slug）
- `skills/quick-kb-import/SKILL.md`（导入时生成 slug）

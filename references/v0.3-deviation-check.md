## 3. 关键对齐项明细

### 3.1 memory-agent 召回排序公式（AGENTS_SPEC §3.5）

```
score = similarity^0.45 × recency_factor^0.20 × impact_factor^0.15 × confidence_factor^0.20
```

类型加权：
- experience（含失败）×1.5（失败再 ×1.2）
- pattern ×1.3 / decision ×1.2 / principle ×1.1 / belief ×0.9 / concept ×1.0 / resource ×0.7

→ dev v0.3 WP3 与 AGENTS_SPEC 完全一致。

### 3.2 maturity 6 态（DESIGN §6.4）

```
captured → understood → validated → applied → teachable
                                            │
                                            └─（长期未触碰/被推翻）─→ deprecated
```

deprecated 强制关联 `relations.supersedes` 或 `relations.contradicts` 至少一项（ADR-011）。

→ dev v0.3 WP1 完全一致。

### 3.3 Knowledge Score（DESIGN §6.6）

```
KS = confidence × log2(1 + reuse) × impact
```

不强制写入笔记；review 时由 manager 计算排序。优先处理两类：
- 高价值低置信（KS 高但 confidence < 60）→ 验证
- 低复用高占用（confidence 高但 reuse = 0）→ 连 MOC 或归档

→ dev v0.3 WP1 / WP10 完全一致。

### 3.4 Decision Ledger 8 字段（DESIGN §8.4）

`problem / options / chosen / reason / rejected / expected / actual / lesson`

- archive 时 lesson 自动派生为独立 experience 笔记到 `07_principles/experiences/`
- 原决策建立 wikilink 指向派生 experience

→ dev v0.3 WP5 / WP7 完全一致。

### 3.5 冲突呈现（AGENTS_SPEC §3.6 + §4.2 + ADR-011）

召回含 `contradicts` → 双方同时返回 + 各自 context + reasoning 说明情境对照 + 缺口提示。

→ dev v0.3 WP8 完全一致；v0.2 已在 query/ingest 部分实现，v0.3 在 memory-agent / advisor 全面落地。

### 3.6 主动提醒 7 类（DESIGN §7.6）

| 事件 | 触发 agent | v0.2 已做 | v0.3 新增 |
|------|----------|---------|----------|
| Ingest 新笔记 | manager | ✓ | — |
| Review 完成 | manager | ✓ | — |
| 长期未触碰 applied | manager | ✓（基于 updated） | 改为基于 maturity |
| 新建项目 | memory | — | ✓ |
| 新建目标 | memory | — | ✓ |
| Capture 某主题素材 | memory | — | ✓ |
| Ingest 检测冲突 | memory | — | ✓（替换 v0.2 manager 降级实现） |

→ dev v0.3 WP9 与 v0.2 实现衔接正确。

## 摘要

RAG（检索增强生成）是 LLM 应用最广泛的架构模式。核心流程：

1. **索引阶段**：文档切分 → 向量化 → 写入向量库
2. **检索阶段**：用户 query 向量化 → ANN 检索 → top-k 召回
3. **生成阶段**：召回片段拼 prompt → LLM 生成答案

## 关键设计点

### 向量库选型

| 类型 | 代表 | 适用 |
|------|------|------|
| 专用向量库 | Pinecone, Weaviate | 大规模、纯检索 |
| 混合数据库 | pgvector, Milvus | 业务数据 + 向量 |
| 内嵌方案 | SQLite-vss, Chroma | 原型/小规模 |

### 分块策略

固定长度切分简单但破坏语义。推荐：
- 按 heading 切粗块
- 滑动窗口合并相邻小块
- 表格/代码整体保留

### 召回排序

单纯向量相似度不够，需要 reranker：
- cross-encoder 重排
- 多路召回（关键词 + 向量 + 图谱）

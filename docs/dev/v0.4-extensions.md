## 4. 工作包详述

### WP1 · quick-kb-normalize 技能

**交付**：批量规整历史笔记。

**核心能力**：
- 扫描指定范围（领域 / 全库 / 仅 v0.1 旧笔记）
- 补全 frontmatter 缺失字段
- 归一标签（对照 `kb.config.yaml` 受控词表）
- **`related` → `relations` 迁移**（V2 关键）：把扁平 `related` 列表按相似度分类到 `relations.supports`，无法判断的留 `related` 兼容
- 标题规范化（kebab-case 文件名）
- 不改正文，仅元数据

**关键点**：
- **幂等**：多次运行结果一致
- **可解释**：每条改动报告"改了什么、为什么"
- **可回滚**：保留 frontmatter 改动前的 diff（写入 `_normalize_log/`）

- **依赖**：v0.3 完成
- **验收**：v0.1 旧笔记批量迁移后 frontmatter 完整、relations 正确

### WP2 · quick-kb-archive 技能

**交付**：安全归档已完成/取消的项目、目标，过期素材。

**核心能力**：
- 状态检查（未关闭的决策/笔记提醒）
- 迁移到 `archive/{projects,goals,reviews,materials}/`
- 更新指向归档对象的 wikilinks
- 不删除，可恢复

**关键点**：
- 与 v0.3 project/archive 工作流不同：v0.3 是项目内的归档（含 lesson 派生），v0.4 是更通用的归档操作（任意对象）
- 跨对象引用更新（避免死链）

- **依赖**：v0.3 完成
- **验收**：归档后无死链，可逆向恢复

### WP3 · quick-kb-stats 技能

**交付**：输出 vault 健康仪表盘。

**指标**：
| 指标 | 计算 |
|------|------|
| 总笔记数 / 各 type 分布 | 计数 |
| 孤立笔记率 | 无入链无出链 / 总数 |
| frontmatter 缺失率 | 字段缺失笔记 / 总数 |
| 置信度分布 | 直方图 |
| maturity 分布 | 6 态计数 |
| Knowledge Score Top 10 | 排序 |
| 高价值低置信清单 | KS 高但 confidence < 60 |
| 低复用高占用清单 | confidence 高但 reuse = 0 |
| inbox 周转时长 | 平均 captured_at → ingest 间隔 |

**输出**：写入 `outputs/reviews/adhoc/stats-YYYY-MM-DD.md` + Obsidian Bases 视图（如启用）。

- **依赖**：v0.3 完成
- **验收**：`stats` 输出完整仪表盘

### WP4 · quick-kb-import 技能

**交付**：从外部库批量导入。

**支持源**：
- Obsidian vault（直接读取，识别 wikilink/frontmatter）
- Notion 导出（CSV/Markdown）
- Logseq（Markdown journal 格式）

**工作流**：
1. 解析源格式
2. 转换为 quick-knowledge frontmatter（不完美字段标 `status: draft`）
3. 写入 `inbox/` 作为待 Ingest 候选（**不直接入库**）
4. 输出导入报告（成功数、降级数、需手动处理数）

**关键点**：
- **不删原库**
- 导入的笔记统一进 inbox，走正常 Ingest 流程
- 重复检测（避免重复导入）

- **依赖**：v0.3 完成
- **验收**：从 Obsidian vault 导入 → inbox 候选笔记

### WP5 · kb.config.yaml 完整支持

**交付**：完整 schema + 校验 + 各技能读取配置。

```yaml
language: zh                       # zh | en
default_domain: ai-engineering
domains: [...]                     # 已注册领域
tags_vocabulary: [...]             # 受控标签词表
review:
  inbox_max_age_days: 7
  orphan_threshold: 0.15
  confidence_decay_months: 6
  structure_drift_count: 30
  structure_drift_ratio: 0.40
proactive_reminders:
  enabled: true
  suppress: []                     # 关闭某类提醒
  quiet_below_notes: 50
  max_per_session: 3
memory_agent:
  min_notes: 50                    # 低于此关闭召回
  weights:                         # 覆盖默认排序权重
    similarity: 0.45
    recency: 0.20
    impact: 0.15
    confidence: 0.20
```

**关键点**：
- 校验：缺失字段走默认值（零配置可用）
- 各技能/agent 读取自己相关的配置段

- **依赖**：v0.3 完成
- **验收**：自定义权重后 memory-agent 召回排序变化

### WP6 · README 多语言

**交付**：对齐 nuwa-skill 模式，5 种语言 README：

| 文件 | 语言 |
|------|------|
| `README.md` | 中文（主） |
| `README_EN.md` | English |
| `README_JA.md` | 日本語 |
| `README_KO.md` | 한국어 |
| `README_ES.md` | Español |

**关键点**：
- 中文为主，其他语言通过顶部语言切换栏互相链接
- 通用结构（badge、效果示例、安装、使用、工作原理、仓库结构）
- 安装方式覆盖：npx skills / 手动（按 runtime）/ 参考

- **依赖**：v0.1-v0.3 完成（要描述最终形态）
- **验收**：5 个 README 结构一致、链接互通

### WP7 · 快速开始指南

**交付**：`docs/quick-start.md`（中英双语段落），面向新用户的 5 分钟上手。

**结构**：
1. 安装（一行命令 + 手动）
2. 初始化第一个 vault
3. 第一条 capture
4. 第一次 ingest
5. 第一次 query（v0.2+）/ advisor（v0.3+）

- **依赖**：v0.1-v0.3 完成
- **验收**：新用户照做能跑通基本流程

## 7. 风险与降级

| 风险 | 应对 |
|------|------|
| normalize 误判 relations 类型 | 不可判断的留 related；提供 dry-run 预览模式 |
| import 字段映射不完美 | 不完美字段标 status: draft，进 inbox 待人工 |
| 多语言 README 维护成本 | 中文为主，其他语言以中文为源翻译；标注最后同步版本 |
| config 校验失败 | 走默认值并警告，不阻塞使用 |

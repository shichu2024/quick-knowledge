# v0.2 · 闭环完整开发文档

> 代号 **loops** · 六闭环打通，知识库开始自维护。引入 manager / research agent 与完整 frontmatter。

---

## 1. 目标

在 v0.1 的最小采集闭环基础上，补齐六闭环剩余部分（Connect / Query / Review / 完整 Normalize），让库能：
- 自动建立双链与 MOC（Connect）
- 强制引用地回答事实问题（Query）
- 周期性健康检查与价值刷新（Review）
- 完整 frontmatter（含 relations / context / value）

**用户体验跃迁**：从"能记"到"能用、能自检"。

---

## 4. 工作包详述

### WP1 · 完整 frontmatter 落地（relations / context / value）

**交付**：升级 v0.1 技能产出的笔记 frontmatter，加入：
- `relations: { supports, contradicts, evolves, supersedes }`（类型化）
- `context`（自由文本可选）
- `value.reuse`（自动，初值为 0）

**关键点**：
- v0.1 产出的笔记**不强制回填**，但 v0.2 起所有新笔记含完整字段
- `related`（V1 兼容）保留，`relations` 优先

- **依赖**：v0.1 完成
- **验收**：新 ingest 笔记含 `relations`/`context`/`value.reuse` 字段

### WP2 · manager-agent（基础能力）

**交付**：`agents/quick-kb-manager-agent.md`，实现 AGENTS_SPEC §1 的**基础能力**：

| intent | 是否本阶段 |
|--------|----------|
| `tidy_inbox` | ✓ |
| `build_moc` | ✓ |
| `recommend_relations` | ✓ |
| `detect_orphans` | ✓ |
| `repair_deadlinks` | ✓ |
| `refresh_value` | ✓（仅入链数计算 reuse） |
| `detect_structure_drift` | 推迟 v0.3（KS 排序依赖 maturity） |
| `proactive_remind` | ✓（manager 事件子集） |

**关键点**：无 embedding 时 similarity 降为标签 Jaccard。

- **依赖**：WP1
- **验收**：能对一个领域生成 MOC、检测孤立笔记、刷新 reuse

### WP3 · research-agent

**交付**：`agents/quick-kb-research-agent.md`，实现 AGENTS_SPEC §2 全部能力。

**关键点**：
- 替换 v0.1 ingest 的内置 LLM 抽取
- 支持长文/PDF/网页（接 defuddle）
- 原子化规则（一笔记一观点）

- **依赖**：WP1
- **验收**：research-agent 处理一篇长文 → 产出 N 条原子笔记 + 摘要卡

### WP4 · quick-kb-connect 技能

**交付**：实现 SKILLS_SPEC §4 完整工作流。

**关键点**：
- 调用 manager-agent 的 `recommend_relations` / `build_moc`
- 写入 `relations`（类型化），不再写扁平 `related`
- 生成 `wiki/mocs/<domain>-moc.md`
- 接 json-canvas 生成 `wiki/maps/<domain>.canvas`（Obsidian 缺失时跳过）

- **依赖**：WP1、WP2
- **验收**：对一个领域运行后，生成 MOC + canvas + 双链

### WP5 · quick-kb-query 技能

**交付**：实现 SKILLS_SPEC §5 完整工作流。

**关键点**：
- **强制引用**（strict 模式默认，hybrid 模式可选）
- 召回结果含 `contradicts` 时**同时呈现双方 + context**（ADR-011，本阶段开始执行）
- 召回为 0 时明确说"未找到"，不编造

- **依赖**：WP1、WP2（用 manager 做召回）
- **验收**：问题 → 答案每句结论都挂 `[[]]` 引用；冲突笔记同时呈现

### WP6 · quick-kb-review 技能（基础版）

**交付**：实现 SKILLS_SPEC §7 工作流的**基础部分**：

**做**：
- 周期快照采集
- `value.reuse` 刷新（调 manager-agent）
- knowledge/project/goal/daily 维度分析
- 健康报告 + 待办清单

**不做**：
- Knowledge Score 排序（依赖 maturity，v0.3）
- 结构演化建议（v0.3）
- deprecated 自动降级提示（v0.3）

- **依赖**：WP1、WP2
- **验收**：`review weekly` → 生成周报 + 待办

### WP7 · Obsidian-skills 集成 + 降级

**交付**：`references/obsidian-integration.md`，说明与 kepano/obsidian-skills 的依赖关系与降级路径。

**集成点**：
| obsidian-skill | 用法 | 缺失时降级 |
|----------------|------|-----------|
| `obsidian-markdown` | wikilink/callout/properties 规范 | 纯 GFM |
| `obsidian-bases` | inbox/areas/goals 仪表盘 | 跳过 .base |
| `json-canvas` | 知识地图 .canvas | 跳过，仅 MOC |
| `obsidian-cli` | 与 Obsidian 应用交互 | 跳过 |
| `defuddle` | capture 抓取干净正文 | 基础 HTML→MD |

- **依赖**：WP1-WP6（技能本体）
- **验收**：装 obsidian-skills 时全功能；不装时降级路径工作

### WP8 · 英文模板

**交付**：`templates/en/*`，与中文版一一对应（concept/idea/daily/resource，外加 v0.2 新涉及的 moc 模板）。

- **依赖**：WP1
- **验收**：`kb.config.yaml` 设 `language: en` 时，技能产出英文模板填充

### WP9 · capture / ingest 升级

**交付**：
- capture 支持完整源类型（PDF / 会议 / AI 对话 / 阅读笔记），接 defuddle
- ingest 改为调用 research-agent，并产出完整 frontmatter
- ingest 加入**冲突检测**（V2 §SKILLS_SPEC §3 第 3 步）

- **依赖**：WP1、WP3
- **验收**：capture URL 接 defuddle；ingest 笔记含完整字段

### WP10 · 主动提醒机制（manager 事件子集）

**交付**：在现有技能工作流中插入 manager 事件的主动提醒：
- Ingest 新笔记 → manager 提示建立 `supports`/`evolves` 关系
- Review 完成 → manager 提示处理高价值低复用笔记

**不做**：memory 事件（v0.3）

- **依赖**：WP2、WP9
- **验收**：ingest 一条新笔记时，自动提示候选关系

## 7. 风险与降级

| 风险 | 应对 |
|------|------|
| 召回质量低（无 embedding） | 标签 Jaccard + 标题关键词；明确告诉用户"召回基于规则，建议运行 normalize 优化" |
| MOC 聚类不准 | 降级为按标签分组；用户可手动调整 |
| Obsidian-skills 未装 | 完整降级路径（见 WP7） |
| 主动提醒变噪音 | 限流：单次 ≤ 3，去重，库 < 50 关闭 |

## 8. 测试要点

| 用例 | 期望 |
|------|------|
| connect 对 10 条笔记的领域 | 生成合理 MOC + 双链 |

| query 命中 contradicts | 双方同时呈现 + context |
| query hybrid 模式 | 库内/推测分段 |
| review weekly | 周报 + 孤立笔记/重复嫌疑清单 |
| review 触发 reuse 刷新 | value.reuse 数值更新 |
| ingest 接 research-agent | 多观点素材拆为 N 条 |
| capture PDF | 文本提取 + 摘要卡 |
| Obsidian 缺失环境 | 跳过 canvas/base，仍产出 MOC |
| 主动提醒限流 | 单次 ≤ 3 |

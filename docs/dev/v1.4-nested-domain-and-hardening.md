# Part A · 嵌套 domain（v1.4.0，已实施）

## A.1 目标

解决「domain 字段扁平，无法表达领域层级」的问题。例如 `rag`、`vector-db`、`retrieval` 三个领域实际属于 `ai-engineering` 的子领域，扁平 domain 无法表达这种归属，导致 MOC 分组、跨领域导航、统计聚合都受限。

## A.2 范围

### in scope

- `domain` 字段支持嵌套路径形式 `parent/child/grandchild`
- `kb.config.yaml` 新增 `domain_taxonomy` 段（声明合法 domain 树）
- ingest / init / connect / query / normalize 全链路感知嵌套 domain
- normalize 新增 `regroup` 动作：把 flat domain 批量迁移到嵌套结构
- 日期类文件名（daily / inbox 时间戳前缀）附带 LLM 提炼的摘要

### out of scope

- 自动从正文推断 domain 归属（保持由 config 显式声明）
- 跨 vault 的 domain 合并
- domain 别名 / 多归属（一个笔记属于多个 domain）

- [x] query 按 parent domain 聚合时，子 domain 笔记被包含
- [x] normalize `regroup` 把旧 vault 的 flat domain 批量迁移到嵌套结构，幂等

## A.5 设计决策记录

| 决策 | 选择 | 备选 | 理由 |
|------|------|------|------|
| domain 分隔符 | `/` | `.` 或 `::` | 与文件系统路径一致，可直接映射目录 |
| 是否强制 domain 必须在 taxonomy 中 | 强制 | 自由字符串 | 受控词表避免拼写漂移 |
| regroup 是否默认开启 | 否，需显式 `--regroup` | 默认开启 | 迁移是大动作，需用户确认 |

# Part B · 测试反馈硬化（v1.4.1+，计划中）

## B.1 目标

### B.1.1 解决的问题

| 问题 | 现状 | v1.4.1+ 后 |
|------|------|-----------|
| connect 降级时 MOC 字段从正文推断 → 60-75% 字段错误 | 唯一产生**数据错误**（非缺失）的降级路径 | 硬约束：MOC 字段必须逐字抄自 frontmatter |
| init 只铺 4 个模板 → experience/principle/belief 等无模板 | project archive 派生 experience 时格式漂移 | 铺全 12 个模板 + schema 升级机制 |

| 归档派生 experience 后 contradicts 关系对未消解 | 冲突闭环最后一公里缺失 | archive 时基于 lesson 自动加 `resolved_by` |

### B-WP3 · import 量表统一 + 弱键去重（P0）

**对应优化项**：O4 + O6

#### 交付物

- `skills/quick-kb-import/SKILL.md` 修订：
  - §3.2 confidence 处理逻辑改为：
    > 原 confidence 若在 [0,1] 保留；若在 (1, 100] 则除以 100 归一；缺失默认 `0.5`。
  - §3.3 重复检测增强为两级：
    - **强键**（自动 skip）：`hash(title + (domain||''))` 命中 OR `source.url` 完全相等
    - **弱键**（报告标注，不自动 skip）：
      - 条件 A：`|sorted(tags_A) ∩ sorted(tags_B)| ≥ 2` 且标题编辑距离 < 0.3
      - 条件 B：`source.url` 的 `domain + path` 相似度 > 0.7
      - 弱键命中 → 报告中加 ⚠「疑似重复 [[X]]，人工确认是否跳过」
  - §4 导入报告模板新增"⚠ 疑似重复清单"段
- bench 新增 case：`import-cross-lang-dedup`（英文标题 vs 中文标题 + 共享 2 个 tag → 触发弱键）

#### 依赖

- 无

#### 关键实现点

- **弱键不阻塞**：弱键命中只在报告里列，不改变导入行为，避免误伤。
- **编辑距离**：用 Levenshtein / max(len) 即可，不引外部依赖。
- **url 相似度**：去除 `https://`、`www.`、尾部 `/` 后做字符串包含或 Jaccard。

#### 验收点

## B.6 风险与降级

### B.6.1 兼容性风险

| 改动 | 风险 | 缓解 |
|------|------|------|
| init 铺 12 模板（原 4） | 已初始化 vault 用户的自定义模板可能被覆盖 | 升级流程严格遵守"已存在则跳过" |

## 附录 · 决策记录

| 决策 | 选择 | 备选 | 理由 |
|------|------|------|------|
| 文档合并策略 | Part A + Part B 同一文件 | 拆两个文件 | v1.4 是连续版本，合并便于追溯 |
| MOC 字段违约时 fail 还是 warn | **fail** | warn | 测试观察到 warn 被 LLM 忽略，必须硬约束 |
| import 弱键命中时 skip 还是提示 | **提示** | skip | 误伤风险高，让人工决定 |
| 反向关系是否自动删除 | **不删** | 自动同步删除 | 保留人工痕迹，避免来回震荡 |
| archive 冲突消解用启发式还是 memory-agent | **启发式** | 等 memory-agent | 启发式覆盖 80% 场景，不阻塞 |
| confidence 量表统一方向 | **0-1 小数** | 百分制 | 与 frontmatter-v0.2 一致，已是主流 |
